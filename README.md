# TriviaAI
## Final Project for STATS 507 - Data Science and Analytics using Python

Trivia has always been a go-to activity for people whether it be recreationally or by watching game shows like Jeopardy! Or Who Wants to be a Millionaire?. In either case, it offers a competitive and engaging way to test knowledge and learn new facts about a variety of topics. This project explores the fine-tuning of a T5-based transformer model to improve performance on a trivia question-answering task using an open trivia database. Overall, this work underscores the complexity of adapting pre-trained language models to specific tasks and emphasizes the importance of data quality and augmentation strategies in achieving performance improvements.
